# Reports Implementation Plan

> Executed inline (superpowers:executing-plans). **Spec:** docs/superpowers/specs/2026-11-22-reports-design.md

**Goal:** `/reports` reproduces the prototype's Reports view with live numbers.

### Task 1: API `GET /api/reports`
- Create `apps/api/src/routes/reports.ts` (`reportRoutes`, requireUser), register in `app.ts`.
- Test `apps/api/test/reports.test.ts`: 401 signed out; with leads New/Referral ×2, LinkedIn ×1 and one archived
  Referral, any signed-in user (a sales rep too) gets `bySource` `[{source:'Referral',count:2},{source:'LinkedIn',count:1}]`
  (count desc, then source asc) and `enquiries` all 0.

### Task 2: Reports page
- Create `apps/web/src/pages/reports/ReportsPage.tsx` + `apps/web/src/api/reports.ts` (`useReports`), route `/reports`,
  remove `ReportsPage` from `Placeholder.tsx`.
- Markup as the prototype: `.page.cols` → `section.card.col-main` "Leads by source" (rows: span label / strong count,
  `.bar > div` width = count/max %), `section.card.col-main` "Enquiry conversion" (`dl.kv`, 200px label column).
- e2e `apps/web/e2e/parity/reports.spec.ts`: title/sub text, card headings in order, a source row with its count and
  a bar, the five enquiry labels with 0; capture `reports`.
- es/fr translations for every phrase.
