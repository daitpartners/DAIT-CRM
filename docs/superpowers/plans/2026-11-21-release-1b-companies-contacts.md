# Release 1B — Companies & Contacts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Companies, Contacts and Locations in the live CRM: tables, duplicate-matching service, API with role visibility, Companies list + 7-tab profile, Contacts page, seeds and tests.

**Architecture:** Same monorepo as 1A. `packages/shared` gains Zod schemas, normalisers and the pure matching ranker; `apps/api` gains three Prisma models, a `companies/` module (visibility, matching queries, routes), and seeds; `apps/web` gains `pages/companies/*` and `pages/contacts/*` built on the 1A Table/Modal/Combobox/FormField components. Every rule lives in the API; the web only renders.

**Tech Stack:** unchanged from 1A (Node 24, Fastify 5, Prisma 6.19, Zod 3.25, React 18, TanStack Query 5, react-hook-form, Vitest 3, Playwright 1.65). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-21-release-1b-companies-contacts-design.md`. Companion: `docs/data-model.md` Module 2, `docs/DAIT-CRM-Specification-v2.md` §5 and §11, prototype `prototype/js/store.js` lines 56–90 (normalisers, matchCompany, matchContact), `prototype/js/data.js` (sample companies, contacts, locations), `prototype/js/views-companies.js` (list and profile layout).

## Global Constraints

- Everything in the 1A plan's Global Constraints still applies (Node ≥ 24, pinned deps ≥ 14 days old, brand tokens, role labels, three languages keyed by English phrase, combobox for ≥ 8 options, escaped output, `safeUrl` for links, secrets only in `.env`, root `npm test` green before every "done" commit, commit trailer `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`).
- All lookup groups needed here (`industry`, `business_category`, `business_type`, `employee_range`, `revenue_range`, `ownership_type`, `contact_type`, `location_type`, `country`, `currency`) already exist and are seeded by 1A `apps/api/src/seed/lookups.ts`. Do not add groups.
- Business number format `CO-0001` (zero-padded to 4, grows past 9999) from a Postgres sequence `company_number_seq`.
- Free-mail domains ignored for matching, verbatim from the prototype: `gmail.com, yahoo.com, outlook.com, hotmail.com, icloud.com` (drop the prototype's test entry `free-prizes.biz`).
- Company status values: `Active`, `Inactive`, `Closed`. Contact type values come from lookup `contact_type`. Location type from lookup `location_type`.
- Pagination format (new, reused by 1C): query `?page=1&pageSize=25&sort=name&dir=asc&q=`; response `{ items, total, page, pageSize }`. `pageSize` max 100.
- Optimistic concurrency: PATCH bodies carry `updatedAt` (ISO string as loaded); mismatch → `409 { error: 'stale' }`.
- Error codes added: `stale`, `domain_taken`, `company_inactive`, `last_primary_contact`.

## Review Focus

1. A company created with website `https://www.Acme.co.uk/about` and another with business email `x@acme.co.uk` must collide on domain `acme.co.uk` (409 `domain_taken`), not create two rows. (Task 3 test `normalises domain before the unique check`.)
2. Two users editing the same company: the second save with the older `updatedAt` must get 409 `stale`, never silently overwrite. (Task 3 test `rejects a stale update`.)
3. A Sales Representative must get 404 (not 403, to avoid leaking existence) for a company they cannot see, and must never see it in the list. (Task 3 test `sales representative cannot read another user's company`.)
4. Deleting or demoting the only primary contact: the API refuses to leave a company with contacts but no primary. Setting another contact primary must atomically clear the previous one. (Task 4 tests `switching primary clears the previous primary` and `cannot unset the only primary`.)
5. The duplicate check must not trust free-mail domains: `john@gmail.com` with company "Northwind" must not match Northwind's row on domain, only on name + country as a review candidate. (Task 2 test `ignores free-mail domains`.)

**Interfaces:**

AND country = ?`.
